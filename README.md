# EDS220 HW4: Visualizing fire scars through false color

## Description

This repository contains files related to the HW4 assignment "Visualizing fire scars through false color" for EDS220, part of the UCSB MEDS 2027 graduate program. In this analysis, Landsat Collection 2 Level-2 atmospherically corrected surface reflectance data from the Los Angeles (LA), California (CA) area, collected by the Landsat 8 satellite, was visualized using true color and false color imagery to detect burn scars from the 2025 Eaton and Palisades fires. CALFIRE fire perimeter data was used to confirm the recorded boundaries of these two fires in 2025.
